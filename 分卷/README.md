建议先读基础卷第3章了解核心方程，再从第1章学习完整推导。结果卷按七条问题线串联文章，第4章可按稳定文献键反查原文。

三卷各自编排目录、公式与参考文献；同一文献的数字引文编号可能不同，文献键保持一致。三份 PDF 应保存在同一目录，才能使用跨卷跳转。原文 PDF 在上一级的 papers/，可通过[可搜索总索引](../paper_index.html)查找；请将索引下载到本地后用浏览器打开。

对应的三个 Bib 文件和共享 preamble.tex 保存在本目录。内容从上一级的 main.tex、sections/ 和 references.bib 生成；请参照[项目说明](../README.md)构建三卷，避免直接编辑生成文件后被覆盖。

分卷保留合订本科学章节、139篇档案和候选清单。拆分本身不增加阅读量；11月12日的[离子与电子加热专题](../specific%20problems/离子加热问题/README.md)实际新增17篇全文，已接入结果卷能量研究线与问题卷原第1.4.5节。未读候选仍单列。
