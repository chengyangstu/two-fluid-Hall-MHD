1. **局地快率**：Hall / GEM 基准 → 色散解释 → 反例与压力机制。
2. **局地到全局**：层长选择 → 供磁与背压 → 驱动、岛合并及尺寸效应。
3. **启动和状态变化**：惯性与非线性加速 → 双稳态 → 递归磁岛、间歇与关停。

5. **第三维**：X 线传播和历史 → 有限活跃长度 → 斜模、湍流和最终状态。
6. **能量与热化**：电子独有重联 → 分物种能量 → 相混合、轨道展宽与熵。
7. **可观测证据**：四极与嵌套结构 → 多物种歧义 → 电势、流速、温度的联合检验。

这些连接是本报告的问题导向阅读顺序，不等于已核实全部作者间的直接引用网络。122 篇都已映射到相关问题线；模型和算法基础文献另有“模型与数值可信度”入口。

## 建议学习顺序

先读《理论与数值基础》第3章总览，分清双流体的两套动量方程与 Hall 欧姆定律，再依下列顺序详细学习。

1. 《理论与数值基础》第1章先按六遍学习路线，跟算分布函数取矩、质心变换、广义欧姆定律、磁冻结和总能量。
2. 再学 Hall / 扩展 MHD、五矩 / 十矩 / CGL、EMHD、约化及陀螺流体、闭合与相混合；最后做附逐步答案的综合练习。教学自设参数不冒充论文算例。
3. 基础卷第2章学习离散、边界、显式 / 隐式推进、数值耗散与验证；再进入《不同文章的结果》第1章的七条问题线，第2章核对实验。
4. 《已解决与未解决的问题》把每条线接到具体论文的结论、缺口及可检验设计。《不同文章的结果》第3章说明覆盖和证据等级，第4章用于反查逐篇原文。

## 重新编译

需要 Python 3、XeLaTeX / BibTeX、ctex 和 Fandol 字体；合订本构建另用 latexmk。分卷构建需要 PyMuPDF，视觉审计还需要 Pillow，选定教学代数核验另需 SymPy。

在项目目录生成三卷（包括多轮交叉引用解析与 PDF 链接处理）：

    python3 scripts/build_split_reports.py
    python3 scripts/audit_split_reports.py

这会从 main.tex、sections/ 和 references.bib 重建分卷源文件，再编译三份 PDF。修改内容时优先编辑这些源文件，避免下一次生成覆盖手工修改的分卷 TeX。仅用 XeLaTeX 单独编译一卷时，跨卷引用需要另外两卷的辅助文件；建议用上述脚本一次生成三卷。

合订本和索引仍可用 ./build.sh 重新生成。索引生成仅用 Python 标准库。需要时可先运行 python3 -m pip install PyMuPDF Pillow SymPy 安装检查依赖。

scripts/build_report_index.py 可重复生成索引、书目与统计。新增核读记录后，可用 scripts/build_story_index.py 更新研究线映射。scripts/build_synthesis_chapter.py 从本轮固定备份和内容块重建第三章；若已手动改过生成的章节，不应直接重跑以覆盖修改。

检索、下载、批次导入、版本合并及 ingest_synthesis_batch.py 是研究过程脚本，不应作为日常构建批量重跑。新增文献先备份并按稳定文献键合并；只有实际全文阅读后才能写入核读状态。
