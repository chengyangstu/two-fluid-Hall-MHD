## 从哪里开始

- `main.pdf`：可直接阅读的中文报告。
- `main.tex`、`preamble.tex`、`sections/`：完整 LaTeX 源文件。所有模型的原理推导集中在第一章；标题用黑体，正文用宋体。
- `paper_index.html`：浏览器打开，可按题名、文献键、年份、状态及要点搜索。支持筛选全部已读 116 篇、本轮续读 15 篇、上一轮精选 39 篇、余量初筛 698 条和优先队列中仍未读的 107 条。完整文献键优先精确匹配；可展开核读要点及初筛理由，并打开本地原文。
- `paper_index.csv`：UTF-8 BOM 编码的索引，可导入文献管理或表格软件。
- `references.bib`：所有登记记录的书目数据；PDF 的参考文献仅列实际引用的条目。
- `papers/`：已经取得的论文、预印本及明确标识的补充资料。以索引中的路径为准，文件名不保证等于最终校正后的文献键。

正文引用先跳到参考文献；其中“全文核读档案”可跳到第七章的逐篇记录，“本地PDF”打开对应原文。某些 PDF 阅读器会限制本地文件链接，此时可通过 HTML 索引打开。

## 阅读顺序

1. 先按第一章 1.1 节的六遍学习路线阅读。1.1–1.4 节从符号、张量、分布函数和速度积分推到广义欧姆定律；拿纸笔跟算，再读磁冻结和能量。
2. 再读五矩 / 十矩、闭合、尺度和能量；后半章学习强导引场、有限回旋半径、混合电子群、不对称层、Hall 撕裂以及电势井标度。1.26–1.30 节新增参数关联、最大熵闭合、KREHM 的 Hermite 矩链、双层撕裂、非线性爆发和 MRX 摩擦模型。
3. 第二章用于了解离散、边界、显式 / 隐式推进、预条件、算例参数和验证要求。
4. 1.37 节的综合练习附逐步答案，用于检查符号、量纲和适用条件。第三至五章分别讨论新现象与争议、未决问题、实验对照；第六章说明检索边界，第七章反查原文。

## 重新编译与更新

在项目目录执行：

```sh
./build.sh
```

需要 Python 3（索引生成仅用标准库）及 TeX Live / MacTeX 中的 XeLaTeX、latexmk、ctex、Fandol 字体。检索、下载和 PDF 审计另需 `requests`、`beautifulsoup4`、`PyMuPDF`。

`build_report_index.py` 由当前目录和核读笔记再生成索引、书目及统计；可以重复执行。`add_reading_batch*.py`、`audit_files.py`、`merge_*.py` 和早期 `download.py` 是研究过程记录，可能覆写后续人工修正，**不要作为日常构建批量重跑**。新增文献应先备份 catalog，再按稳定文献键合并；全文核读状态只能在实际阅读后写入。

检查报告见 `research/qa/delivery_audit.json`；图像预览与 HTML 搜索验证记录也在 `research/qa/`。本报告没有声称运行或复现论文中的大规模等离子体模拟。

教学推导的选定代数与数值例核验脚本为 `scripts/verify_tutorial_derivations.py`，另需 SymPy；结果见 `research/textbook_revision/derivation_checks.json`。普通 LaTeX 编译不需要 SymPy。
