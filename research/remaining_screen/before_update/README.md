# Hall MHD 与双流体磁重联调研

检索截止：2026-11-10；重点全文核读更新：2026-11-11。当前为 **101 篇精读版**，**尚未完成所有候选文章的下载、资格筛选和全文阅读**。

## 从哪里开始

- `main.pdf`：可直接阅读的中文报告。
- `main.tex`、`preamble.tex`、`sections/`：完整 LaTeX 源文件。所有模型的原理推导集中在第一章；标题用黑体，正文用宋体。
- `paper_index.html`：浏览器打开，可按题名、文献键、年份、状态搜索，筛选“已全文核读”101 篇或“本轮重点精选”39 篇，展开核读要点，并打开本地原文。
- `paper_index.csv`：UTF-8 BOM 编码的索引，可导入文献管理或表格软件。
- `references.bib`：所有登记记录的书目数据；PDF 的参考文献仅列实际引用的条目。
- `papers/`：已经取得的论文、预印本及明确标识的补充资料。以索引中的路径为准，文件名不保证等于最终校正后的文献键。

正文引用先跳到参考文献；其中“全文核读档案”可跳到第七章的逐篇记录，“本地PDF”打开对应原文。某些 PDF 阅读器会限制本地文件链接，此时可通过 HTML 索引打开。

## 这一版实际做到了什么

原始候选 807 条；去掉已确认重复及排除记录后为 799 条，仍含需要进一步分类的外围研究。308 条非重复候选已关联可解析 PDF，**不等于 308 篇均已人工验证相关性和文件身份**。

101 篇已完成所记录版本的正文、方法、结果、讨论和适用附录阅读，并核对关键公式、图表和计算参数。正文的研究判断只使用这些已核读文章；不是把未读文章的摘要改写为结论。每篇的范围、页码、图号、发现、限制与本报告判断见第七章或 `research/reading_notes/verified.json`。其中明确包含理论、算法、实验及动理学对照，不代表 101 次独立 Hall 模拟。

已区分 Hall / 电子—离子双流体、五矩 / 十矩、电子惯性、EMHD、约化和陀螺流体；PIC 与实验作为对照。离子—中性、对等离子体、相对论、学位论文、海报和幻灯片仍有部分候选待逐项分流。

新版 PDF 共 179 页，第一章模型原理与推导为正文第 1–34 页。标题用黑体 / Heros，正文用宋体 / Termes；已检查编译、引文、本地 PDF 链接、索引筛选和新增页面排版。

本轮从已有 PDF 中精选并新增全文核读 39 篇，共 538 个原文物理页（含封面和参考文献，页数不作为独立证据数量）。队列、选择原则、全文提取、关键页图像及逐篇笔记位于 `research/read_to_101/`。没有用重复版本、海报或学位论文凑数，本轮没有新增下载。

重点补入最大熵矩闭合、KREHM 相混合与加热、斜撕裂的条件比较、爆发增长与次级磁岛、非均匀片传播记忆、DG / GPU 隐式数值方法、MRX 电子层、UTST 势降及三维 EMHD 实验。另有 698 条候选尚未完成全文核读，具体下一步见 backlog。

## 阅读顺序

1. 第一章从分布函数、速度矩、两物种方程、准中性和广义欧姆定律开始；先学清楚谁冻结、谁支撑 X 点电场。
2. 再读五矩 / 十矩、闭合、尺度和能量；后半章学习强导引场、有限回旋半径、混合电子群、不对称层、Hall 撕裂以及电势井标度。1.26–1.30 节新增参数关联、最大熵闭合、KREHM 的 Hermite 矩链、双层撕裂、非线性爆发和 MRX 摩擦模型。
3. 第二章用于了解离散、边界、显式 / 隐式推进、预条件、算例参数和验证要求。
4. 第三至五章分别讨论新现象与争议、未决问题、实验对照；第六章说明检索边界，第七章反查原文。

## 重新编译与更新

在项目目录执行：

```sh
./build.sh
```

需要 Python 3（索引生成仅用标准库）及 TeX Live / MacTeX 中的 XeLaTeX、latexmk、ctex、Fandol 字体。检索、下载和 PDF 审计另需 `requests`、`beautifulsoup4`、`PyMuPDF`。

`build_report_index.py` 由当前目录和核读笔记再生成索引、书目及统计；可以重复执行。`add_reading_batch*.py`、`audit_files.py`、`merge_*.py` 和早期 `download.py` 是研究过程记录，可能覆写后续人工修正，**不要作为日常构建批量重跑**。新增文献应先备份 catalog，再按稳定文献键合并；全文核读状态只能在实际阅读后写入。

检查报告见 `research/qa/delivery_audit.json`；图像预览与 HTML 搜索验证记录也在 `research/qa/`。本报告没有声称运行或复现论文中的大规模等离子体模拟。
