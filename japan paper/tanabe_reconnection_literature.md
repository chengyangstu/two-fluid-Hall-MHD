## 可直接发给 Codex 的下载指令

读取本 Markdown 清单，在当前仓库下建立 `literature/`，按 01–07 目录下载论文。先下载 ★，再下载其余。使用 DOI 或原题名定位出版商、arXiv、J-STAGE、机构知识库、IAEA 等合法开放全文；允许使用本人已有的合法订阅权限，但不要绕过付费墙或访问限制。

1. 下载前按 DOI 去重，并核对英文题名、作者、年份与清单一致。对于没有 DOI 的条目，用准确题名和年份核对。
2. 文件命名：`Year_FirstAuthor_ShortTitle.pdf`。期刊最终版优先，预印本注明 `_preprint`，会议稿注明 `_conference`。
3. 检查 PDF 文件头、文件大小以及第一页标题，禁止把 HTML 登录页/错误页面保存成 PDF。
4. 生成 `literature/index.md` 和 `literature/index.csv`：category, first_author, year, title, doi, source_url, local_path, version, status。状态为 downloaded / already_exists / unavailable / needs_manual_access。
5. 遇到无法合法获取全文的条目，保留 DOI 和访问状态，继续下一篇，不要制造文件。先完成清单，不擅自扩展搜索范围。
6. 若要扩展目录，单独从上述作者官方目录、ORCID、Crossref 等发现相关论文并生成候选清单，按 DOI 去重。不要将不相关论文混入专题目录。
